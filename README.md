# AI Partners at Work 🏢

あなたのAIパートナーは、今日も働いています。

Claude Codeのエージェントたちが働く様子を、チャットログの代わりに**3Dオフィスを眺めて**見守るアプリです。AIパートナーは恋愛やお世話の相手じゃなくて、**一緒に働く仲間**——そういう景色を当たり前にするためのプロジェクトです。

エージェントがファイルを読むと本を読み、コードを書くとデスクでカタカタ、作業が終わるとバンザイして喜びます。昼は明るいオフィス、夜は星空とデスクランプ。

## 特徴

- **設定変更ゼロで動く**: Claude Codeが自動保存するセッション記録（`~/.claude/projects/**/*.jsonl`）を監視するだけ。hooksの設定も不要
- **依存パッケージなし**: Node.js標準機能のみ。`npm install`不要
- **全プロジェクト対応**: 並行して動く複数セッションを、それぞれ別のキャラクターに自動割り当て
- **状態表示**: 「📖 よみこみ中」「⌨️ コーディング中」「🤔 うーん…」など、今なにをしているかが吹き出しでわかる
- **昼夜切り替え**: 時刻で自動切り替え＋手動ボタン
- **観察モード**: 右下のボタンでキャラクターにカメラが寄って作業を見守れる
- **VRMアバター対応**: VRoid Studioなどで作った自分のキャラクターに差し替え可能（表情・まばたき・揺れもの付き）

## 使い方

Node.jsが入っていれば：

```bash
node server.js
```

ブラウザで http://localhost:3939 を開くだけ。あとはClaude Codeで作業を始めると、キャラクターが動き出します。

## 自分のキャラクターを使う

1. [VRoid Studio](https://vroid.com/studio) などでキャラクターを作り、VRM形式でエクスポート
2. `public/avatars/` にVRMファイルを置く
3. `public/main.js` の `AVATARS` 配列にファイル名を設定（`null` にするとデフォルトのちびキャラ）

```js
const AVATARS = [
  '/avatars/your-character-1.vrm',
  '/avatars/your-character-2.vrm',
  null,  // 3人目はちびキャラのまま
];
```

キャラクターの名前や色は同ファイルの `CONFS` で変更できます。

## 仕組み

```
Claude Codeセッション（複数可）
  └ セッション記録(JSONL) → fs.watchで監視 → SSE配信 → Three.jsの3Dオフィス
```
